## 🚀 Local Development / 本地预览

```bash
# Clone the repo / 克隆仓库
git clone https://github.com/July0709/July0709.github.io.git
cd July0709.github.io

# Serve locally — pick one / 任选一种方式启动本地预览
python -m http.server 8000        # Python
npx serve .                       # Node
# 或在 VS Code 中使用 Live Server 扩展
```

Then open <http://localhost:8000>.
然后在浏览器打开 <http://localhost:8000>。
