最近在研究建立个人知识库有关的事情，突然很想写一篇"我的知识体系进化史"。

## 中学：一百页本子的豪情

太久远的记不清了，初中以前都比较贪玩，成绩平平，就从中学说起吧。

八年制的我，勉强算是一个在应试教育中取得胜利的学生。初高中生活，确实仰赖体系完善的笔记本。

上高中之前，应该是疫情阶段的网课时期，我在网上看到了 Whynot 错题本——一位上交大同学分享的笔记。他记得很全，对于如何做笔记、如何做错题本都有很好的参考。

那时我大为震撼。彼时我虽然已经将整理笔记和错题本格式化多年，但何泰然师兄的整理，给了我一种全新的视角。

我很喜欢手写笔记的感觉。**知识体系整理的过程，就是把一团麻线理清楚的过程。** 做笔记是为了更好地记忆知识点，切勿流于表面。

越来越长大，我愈加发现：我们并不是为了展示与证明。许多过程，或是乐在其中，或是为自己有一个交代，就足够了。

记得初三的时候，拿着邻居老姨赠予的 100 页本子，我便生出一股豪情——现在离中考还有 100 天，我一天整理一道错题，把这本本子写满，便上考场。

最后虽然没有写满 100 页，数学也只是过得去的水平（110/120），却意外收获了学业特别奖奖学金。

可见，有的时候，就是需要"但行好事，莫问前程"。

这个过程坚持下来，也让曾经的同学发出"你变了，又好像没变"的评价。

## 高中：在困境中，靠读书与整理找到方向

中考结束的时候，我参加了汕头金中的自主招生。

其实我的数理化并没有金中三年那些同学好，三年的高中生活也让我接受了作为一个"平庸"的存在。我还是比较庆幸，自己以优异的中考成绩加成通过自主招生，进入了理科试验班（信息学方向）——即使三年中，我被 C 语言和各种数理难题虐得体无完肤。

在困境中指引我方向的，还是读书与整理知识体系。

我在小红书上曾发表过一篇关于高三笔记整理的拙见，此处不再赘述。大抵关键是两点：**专题意识，与领域词汇积累。** 后来数年，面对高等数学等理工类课程，我也采取类似方法肢解。

这个过程中，我开始不再在乎自己因为考试获得的不那么好的即时评价，也逐渐忽略了身旁的喧嚣。

直到最近又被许多事情扰得心烦时，一位师兄给出了"结庐在人境，而无车马喧"的点破——我又想起了那时笃行的模样。

可是当时我们好像只有一个目标。现在，我们有太多太多的路要走。

那时稚嫩的笔迹写出来的知识体系，现在看来不失为一种回忆。**活页本的厚重带给我困境中的成就感，也让我养成了条理性与纪律性。**

每做完一个专题，不管有过多少个红叉，都要继续往前走。

## 大学：从 OneNote 到 Obsidian

进入大学，无纸化的风也吹到了我身边。

活页本的厚重似乎被视为旧时代的糟粕，大家喜欢用平板记笔记。我却独爱纸质书的厚重，课堂随记依然写在课本上——虽然每次背着"蓝色生死恋"上学时，会觉得自己似乎在横跨太平洋。

大一的理工科课程和系统解剖学，我依然习惯活页本与 A4 纸，后来转到 OneNote。OneNote 我用了很久，很喜欢它无限延展的画布和侧边栏设计。同时我开始使用 Word，发现了 Word 里可以打书签。

那个时候，我用 Word 和 OneNote 完成了大一大二的很多笔记，包括后来流传颇广的有机化学、医学遗传学笔记。

**系统化笔记的方式让我取得了不错的绩点，也拿下了国家奖学金。** 虽然绩点仅仅作为面试的入场券，大三我也迎来了医学课程高压下的绩点猛降——但彼时通过这种方式，每一天都有每一天的雀跃，进一步有进一步的欢喜。

直到最近，我开始使用 Obsidian。

起初是在组会和团队文档中，看到师兄建设得相当完善的 Obsidian 笔记，决定狠下心来试试。直接促使我转向 Obsidian 的原因，是我的 Claude 账户被封号了，不得不导出数据。这时候 Obsidian 成为了一个关键选择，然后便一发不可收拾。

早在三年前，我就听过 Obsidian 的功能强大之处，但一直对它的复杂度望而生畏。实际上入门之后发现并不难。

很多时候，Obsidian 只是作为一个容器：储存我遇到的知识，分门别类地摆放好，包括用网页插件捕获 YouTube 上的知识。Markdown 语法，实质上也不难学。

在使用 Obsidian 作为大本营之前，我很长时间潜伏在 VS Code 里，很多打开 Markdown 浏览的过程都是用 VS Code 完成的，它的插件市场也十分齐全。彼时用 VS Code，还可以非常方便地编辑我建设的网页。

在 VS Code 中用 Markdown 记笔记的过程，也为我后来的一个网站——"南医八年知识库"——的建设埋下了伏笔。

**毕竟，准备的食材越丰富，能够做出的菜肴越多样。**

## 尾声：有些东西一直没有变

如今，我已经将 Obsidian 作为我科研知识的大本营。

这么多年过去，工具的变迁背后，是现实情境的不同。

以前我整理知识，是因为考试终究有一个范围；现在整理知识，却是在面对一个没有边界的问题。

但好像有些事情一直没有改变——

> **面对一团麻线，先坐下来，把它一点点理清楚。**

可能，这也是我们经常在研究场合听到的那句"你要讲好一个故事"背后的深意吧。
